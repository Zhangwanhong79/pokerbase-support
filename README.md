# 终极扑克基地

技术支持与隐私政策。网页版：<https://zhangwanhong79.github.io/pokerbase-support/>

## 技术支持

终极扑克基地是一款保存在本机的扑克练习工具。积分和道具是虚拟计数，只用于练习计分，不能兑换现金。

使用中遇到问题，请发邮件到 zhangwanhong@gmail.com。也可以在应用首页打开「提交反馈」，用系统分享把内容发出去。

## 隐私政策

更新日期：2026年10月16日

### 存在这台设备上的内容

- 练习记录、积分、道具、外观和订阅状态的本地标记，都保存在本机。
- 卸载应用后，这些内容会一起被系统清除。

### 我们不收集的内容

- 不要求手机号、位置、姓名或通讯录。
- 没有账号，练习记录不会上传。

### 订阅

- 订阅由 Apple 处理。付款信息留在 Apple，本应用拿不到卡号。
- 订阅后可以直接补满积分和道具。未订阅时，看完倒计时再补满。

### 联系

对这份说明有疑问，请发邮件到 zhangwanhong@gmail.com。
